# 纸间 · Markdown 排版工作台

浏览器内将 Markdown 转为 PDF，再用 PDF.js 显示相同 PDF 字节。下载保存已经预览的 Blob，不走第二套打印或排版流程。

## 本地运行

安装有 Node.js 的电脑，在项目目录执行 `node server.mjs`，浏览器打开 http://127.0.0.1:4173。没有运行时 npm 依赖。

## 功能

- UTF-8 Markdown 导入、编辑、导出与本机草稿。
- 标题、嵌套列表、GFM 表格、引用、普通代码块和链接。
- A4 / Letter、三种版式、字号、行距、页边距、段落留白、颜色与页码。
- 内嵌 Noto Sans SC 正体与粗体，PDF 文字可选择、链接可点击。
- 真 PDF 分页预览、缩放、版本 SHA-256；有未同步修改时禁止下载旧版。
- 标题孤行处理、表头重复、表格行不拆分、手动分页。
- 默认私有 Sites 发布，静态托管，无文档上传接口、无分析统计脚本。

## 支持边界

当前不渲染 HTML/CSS、图片、数学公式或 Mermaid；检测到相关内容会提示并阻止导出。字体覆盖不能保证所有 Unicode、Emoji 或其他复杂文字，必须检查真实 PDF 预览。PDF.js 与下载文件采用同一份 PDF 数据，缩放与不同阅读器的抗锯齿效果可能不同，但不重新流式排版。

大文档限制为 100,000 字符。单个表格行若高于整页可用高度，应拆分成多行。非 PDF 字体的 italic 标记使用同一字体面，不提供独立斜体字形。

## 实测依据

2026-10-21，以 `dist/sample-resume.md` 对三家默认流程测试，原始 PDF 与逐页检查记录在工作区 `research/resume-test`。测试结论只能代表该样本、当时版本和默认选项。
